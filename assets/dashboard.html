🎨 外观主题

🎯 每日目标（可选功能）

开启后，概览页显示当日目标进度与连续达成天数。编码口径 = 开发工具 + AI编程 两类合计。 目标与连续达成均为即时计算、不落盘；修改目标后，连续达成按新目标重算。
两项都为 0 = 无生效目标（连续达成不计数）。

✨ AI 洞察（可选功能）

AI 洞察默认关闭（隐私优先）。开启后，聚合统计会发送到你选择的 API 端点； 规则洞察始终离线。可选用内置 provider 预设，或选「自定义」填写任意 OpenAI 兼容端点。

💲 AI 模型价格（成本估算）

成本估算 = Token 数 × 单价 ÷ 1,000,000，单价单位 USD / 百万 Token（输入为 USD，输出通常更贵）。 内置常见模型价目表（量级参考，会随厂商调整），可在此覆盖未收录/价格变动的模型——保存后用于时间轴/对比/成本统计。

🗄️ 数据备份

打包数据目录（各日期文件夹 + config.json / app_groups.json / aliases.json， 已排除 .log / 临时 / 备份大文件）为 zip 一键下载，用于迁移或存档。

♻️ 数据恢复

选择上文备份生成的 zip 上传，解压校验后按日期目录/配置合并覆盖到当前数据目录。 相同日期目录会被覆盖、缺失的会补齐；不会删除已有的其他数据。

🔒 访问口令

是否启用口令由数据根目录 config.json 的 dashboard_token 决定（缺失/为空 = 关闭）。开启后所有 API 需携带 X-Dashboard-Token 请求头；本机浏览器首次会在右上角输入口令并记住。 本页面不会显示/修改口令。
